Laboratório 1 – Criando sua primeira página HTML
🎯 Objetivo:
Criar uma página web simples utilizando as tags HTML aprendidas até agora, incluindo títulos, parágrafos, listas, imagens, símbolos e emojis.

📋 Instruções:
Crie um arquivo chamado meu_site.html e construa uma página com o seguinte conteúdo:
1. Título da página:
Use a tag <title> no <head> para definir um título visível na aba do navegador.
2. Cabeçalho principal:
Utilize a tag <h1> para dar boas-vindas ao visitante do seu site.
3. Subtítulo com <h2> e <h3>:
Crie uma pequena apresentação sua com subtítulos usando <h2> e <h3>.
4. Parágrafos com texto:
Use pelo menos dois parágrafos (<p>) para descrever seus hobbies, gostos ou um tema de sua escolha.
5. Linha horizontal e quebra de linha:
Insira uma linha horizontal (<hr>) separando seções do conteúdo.
Utilize a tag <br> onde quiser forçar uma quebra de linha.
6. Listas ordenadas e não ordenadas:
Crie uma lista ordenada (<ol>) com pelo menos 3 itens (ex: suas metas para o ano).
Crie uma lista não ordenada (<ul>) com seus filmes, músicas ou comidas favoritas.
7. Imagem:
Insira pelo menos uma imagem utilizando a tag <img>, com texto alternativo (alt). Pode ser da internet ou uma imagem local.
8. Símbolos e Emojis:
Utilize pelo menos 3 símbolos HTML (ex: &copy;, &euro;, &hearts;).
Utilize pelo menos 3 emojis no conteúdo (ex: 😄 🎵 🍕).
