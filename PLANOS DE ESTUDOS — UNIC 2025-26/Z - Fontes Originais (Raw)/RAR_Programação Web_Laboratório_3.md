Laboratório 3 – HTML e CSS
Objetivo:
Criar um pequeno website composto por várias páginas HTML interligadas, aplicando os conceitos básicos de HTML e CSS aprendidos nas aulas.
Requisitos do Trabalho
O website deve conter:
Mínimo de 3 páginas HTML;
Uso obrigatório dos 3 tipos de CSS;
Menu de Navegação (Todas as páginas devem possuir um menu com links);
Aplicar uma imagem no fundo (Escolher com cuidado, pensando no usuário, e que ocupe a tela inteira);
Usar as tags div, footer (Entender o comportamento delas).
