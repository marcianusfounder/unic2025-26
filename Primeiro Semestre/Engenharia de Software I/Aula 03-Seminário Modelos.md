Modelos de processos de software

Quais são as desvantagens do modelo em espiral?

É um modelo muito rígido.

Só é útil para projetos pequenos e com poucas mudanças.

É difícil avaliar os riscos.

Necessita de uma especificação completa dos requisitos.

No modelo em V, os testes são representados à direita e as especificações do sistema, à esquerda.

Verdadeiro.

Falso.

Um cliente solicita o desenvolvimento de um banco de dados para o seu site. Qual modelo de desenvolvimento é mais adequado?

Modelo em cascata.

Modelo em espiral.

Modelo incremental.

Nenhum dos anteriores.

O modelo em cascata é caracterizado por:

Iterações e entregas frequentes.

Uma sequência linear de fases.

Alta flexibilidade para mudanças.

Foco em testes unitários.

Qual modelo de processo é mais adequado para projetos com requisitos bem definidos e estáveis?

Ágil.

Em cascata.

Prototipação.

Espiral.

O modelo ágil se destaca por:

Documentação extensa.

Planejamento detalhado no início do projeto.

Flexibilidade e adaptação às mudanças.

Foco em fases sequenciais.

Quais são algumas das metodologias ágeis mais conhecidas?

Scrum e Kanban.

UML e BPMN.

Cascata e Prototipação.

RUP e XP.

Qual dos seguintes modelos é mais adequado para projetos com requisitos mutantes e um cliente muito envolvido?

Cascata.

Espiral.

Ágil.

Prototipação.

O modelo ágil se baseia em:

Documentação exaustiva e planejamento detalhado.

Iterações curtas, colaboração e adaptação à mudança.

Fases sequenciais e rígidas.

A construção de um protótipo completo no início do projeto.
