# 🏷️ Guia de Estudo: Tag D (Desenvolvimento & Tecnologias Web)

> [!important] 🎯 Objetivo da Tag D
> Dominar a arquitetura e desenvolvimento Web de ponta a ponta:
> 1. **Arquitetura Web Cliente-Servidor:** Protocolo HTTP/HTTPS, Métodos REST (GET, POST, PUT, DELETE), Códigos de Status (200, 404, 500).
> 2. **Estrutura e Estilização:** HTML5 Semântico, CSS Grid, Flexbox e Animações CSS com `@keyframes`.
> 3. **Lógica e Assincronismo:** JavaScript Moderno (ES6+), manipulação dinâmica do DOM, Promises e consumo de APIs REST com `fetch()` e `async/await`.
