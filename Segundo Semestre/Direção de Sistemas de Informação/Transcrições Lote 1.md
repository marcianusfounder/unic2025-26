**EXERCICIO 3**
Uma empresa angolana desenvolveu um sistema de gestão hospitalar para controlar:
* marcação de consultas;
* emissão de receitas;
* histórico clínico dos pacientes.

Antes da implementação definitiva, a empresa decidiu realizar testes de validação.

Durante os testes:
* alguns médicos afirmaram que o sistema era lento;
* certos pacientes não conseguiam finalizar o agendamento;
* os relatórios apresentavam informações incompletas;
* alguns utilizadores tiveram dificuldades em utilizar a interface.

**Questões**
1. Explique o objetivo dos testes de validação no contexto apresentado.
2. Diferencie:
   * teste Alfa;
   * teste Beta.
3. Identifique quais problemas poderiam ser descobertos:
   * no teste Alfa;
   * no teste Beta.
4. Justifique por que os testes de validação são importantes antes da entrada em produção.
5. Caso os problemas identificados não sejam corrigidos, quais poderão ser os impactos para:
   * os utilizadores;
   * a organização;
   * os pacientes.
6. Proponha duas melhorias que a equipa de desenvolvimento deve realizar antes da entrega final do sistema.

**Exercicio 2**

Um banco pretende implementar um sistema de informação para aprovação automática de crédito.

A direção de TI considera o projeto bem-sucedido porque:
* o software funciona sem erros críticos;
* os testes foram aprovados;
* a plataforma está estável.

Entretanto, a direção comercial afirma que:
* os clientes continuam insatisfeitos;
* o tempo de aprovação não diminuiu significativamente;
* houve redução nas vendas.

**Questões**

1. Explique a diferença entre:
   * visão de TI;
   * visão de negócio.
2. O projeto pode ser considerado bem-sucedido? Justifique.
3. Identifique os indicadores que cada área utilizou para avaliar o projeto.
4. Que tipo de conflito organizacional está presente?
5. Como alinhar os objetivos tecnológicos aos objetivos de negócio?
